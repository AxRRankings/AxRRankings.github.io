AxR tournament commands. Make one BDFD command per block: the trigger is the first word (tjoin, tleave, ...). Prefix is 1.
Keep these scripts private: the key lets anyone run staff actions through the API.

==================== TRIGGER: tjoin ====================
Usage: 1tjoin
Join the tournament (anyone in the server).

$nomention
$httpAddHeader[Content-Type;application/json]
$httpPost[https://axrrankings.vercel.app/api/tourney;{"key":"YOUR_TOURNAMENT_KEY","action":"join","user":"$authorID","text":""}]
$httpResult[msg]

==================== TRIGGER: tcreate ====================
Usage: 1tcreate <mode> <name>  e.g. 1tcreate SWORD Halloween Cup   (STAFF)
Open a new tournament. Mode is optional (SWORD, AXE, UHC, DPOT, NPOT, SMP, SMACE, EMACE, CART, CRYSTAL). Do not use quote marks in the name.

$nomention
$onlyPerms[manageserver;❌ Only staff can use this command.]
$httpAddHeader[Content-Type;application/json]
$httpPost[https://axrrankings.vercel.app/api/tourney;{"key":"YOUR_TOURNAMENT_KEY","action":"create","user":"","text":"$message"}]
$httpResult[msg]
